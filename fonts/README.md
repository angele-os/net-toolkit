# Polices

Ces polices sont auto-hébergées : elles sont servies par le site lui-même, sans requête vers un service tiers, ce qui respecte la CSP `font-src 'self'`.

| Fichier | Police | Auteurs | Licence |
|---|---|---|---|
| `inter-latin-wght-normal.woff2` | Inter (variable, graisses 100 à 900, sous-ensemble latin) | The Inter Project Authors | SIL Open Font License 1.1 |
| `fraunces-latin-opsz-normal.woff2` | Fraunces (variable, taille optique, sous-ensemble latin) | The Fraunces Project Authors | SIL Open Font License 1.1 |
