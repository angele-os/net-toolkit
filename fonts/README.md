# Polices

Ces polices sont auto-hébergées : elles sont servies par le site lui-même, sans requête vers un service tiers, ce qui respecte la CSP `font-src 'self'`. Ce sont les mêmes fichiers que ceux du portfolio ([ange-bonkoski.fr](https://ange-bonkoski.fr)) : les deux sites partagent la même identité visuelle.

| Fichier | Police | Rôle dans l'interface | Auteurs | Licence |
|---|---|---|---|---|
| `newsreader-latin-opsz-normal.woff2` | Newsreader (variable : graisses 200 à 800, taille optique 6 à 72, sous-ensemble latin) | Titres et grands chiffres | The Newsreader Project Authors (Production Type) | SIL Open Font License 1.1 |
| `newsreader-latin-wght-italic.woff2` | Newsreader Italic (variable : graisses 200 à 800, sous-ensemble latin) | Intertitres en italique | The Newsreader Project Authors (Production Type) | SIL Open Font License 1.1 |
| `instrument-sans-latin-standard-normal.woff2` | Instrument Sans (variable : graisses 400 à 700, largeurs 75 % à 100 %, sous-ensemble latin) | Interface et textes | The Instrument Sans Project Authors | SIL Open Font License 1.1 |
| `ibm-plex-mono-latin-400-normal.woff2` | IBM Plex Mono Regular (sous-ensemble latin) | Données techniques : adresses IP, masques, préfixes, configurations | IBM Corp. | SIL Open Font License 1.1 |
